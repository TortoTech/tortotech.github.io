专注模式（Focus Mode）是 Torto（小龟阅读）的**核心精读体验**。与传统阅读器将电子书简单机械切分为固定页码不同，专注模式将书籍解析为自然的阅读单元（段落、列表、引用块、代码块、表格、图片与图注），并让当前阅读内容始终保持在视野舒适的居中起读线上。

其余干扰元素（侧边栏、菜单等）默认收起，高亮、随段笔记、折叠脚注与 AI 伴读对话均紧密跟随当前段落。

---

## 开启与切换

- **阅读器顶部菜单**：点击右上角菜单，选择「专注模式」；再次点击「经典模式」可切回单栏、双栏或纵向滑动视图。
- **全局偏好设置**：在 **设置 → 阅读 → 阅读模式** 中选择「专注模式」（默认）。该设置为全局偏好，对所有导入书籍生效。
- **快捷键**：使用 `Ctrl + ,` 可随时调出设置面板。

:::tip[扫描版 PDF 书籍]
专注模式需要可排版的文字内容。对于扫描版 PDF，请先通过 **设置 → OCR** 开启识别服务，在阅读器中切换为 **OCR 排版视图** 后，即可无缝开启专注模式；切回原始 PDF 会自动恢复为常规页面视图。
:::

## 逐段漫游与视线锚定

在专注模式下，正文按段落自然推进，当前段落享有稳定的居中起读位置：

| 按键 / 操作 | 功能描述 |
| :--- | :--- |
| `↑` / `↓` | 上一段 / 下一段（按段落平滑推进） |
| `←` / `→` | 跳转至上一节 / 下一节 |
| **鼠标滚轮** | 逐段平滑滚动（一次推进一个完整段落） |
| **点击任意段落** | 直接将该段设为当前聚焦段落 |
| **拖动滚动条** | 释放时自动吸附对齐到最近段落 |
| `F11` | 开启 / 退出无边框沉浸全屏 |

:::note[为什么视线保持居中？]
传统阅读器在不同长度段落间翻页或跳转时，文字起始位置忽上忽下，极易引起视觉疲劳。Torto 的专注模式对较短段落固定从居中起读线开始，只有超长段落才向外平滑展开，阅读视线始终平稳沉静。
:::

## 快捷键精读工具箱

专注模式为深度阅读量身定制了全键盘快捷操作：

| 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| `空格 (Space)` | 唤起操作栏 | 在当前段落旁呼出快捷操作菜单 |
| `Tab` | 随段 AI 伴读对话 | 打开绑定在当前段落的 AI 聊天窗口，追问、解析与翻译不串上下文 |
| `1` | 随段高亮 | 为当前段落添加彩色高亮标记 |
| `2` | 随段笔记 | 为当前段落添加读者笔记，精准附在原文旁 |
| `3` | **智能按句拆读** | 将长难段落切分为清晰单句，成对标点与引号完好保留 |
| **左 `Alt`** | **展开 / 收起折叠脚注** | 当前段落的注释自动折叠为小标记，按键瞬时弹出查看，再次按下关闭 |
| `Ctrl + H` | **隐藏 / 显示鼠标光标** | 隐藏鼠标指针，消除屏幕杂讯，享受纯键盘精读 |
| `Ctrl + F` | 全书快速搜索 | 快速查找书中词句，精准直达目标段落 |
| `Ctrl + Q` | 返回书架 | 快速退回封面书架 |

## 核心能力解析

### 1. 智能按句拆读 (`3`)
遇到长句密集的学术论著或经典译作时，按下快捷键 `3`，阅读器会自动在句子边界插入呼吸间隙，并将双引号、括号及注脚成对保留，大幅降低阅读负担，方便逐句咀嚼推敲。

### 2. 随段 AI 伴读与公式图表 (`Tab`)
- **上下文不串段**：每个段落拥有专属的对话窗口。打开时自动附带该段精准上下文与原文链接。
- **排版优美清晰**：AI 回答的公式、数据表格与流程图均由阅读器直接排版呈现，图表支持点击放大。
- **实用快捷指令**：在对话框输入 `/summary` 可快速总结本章要点，`/search` 检索全书并整理答案，`/rewrite` 润色改写，`/extract` 提取关键术语。

### 3. 复杂表格复制为 Markdown
专注模式对复杂统计表格（含跨行、跨列与多行文本）提供清晰排版，支持一键将表格复制为标准 Markdown 文本，方便整理到个人笔记工具中。

### 4. 零干扰纯净环境
配合 **隐藏鼠标（`Ctrl+H`）** 与 **`F11` 全屏**，界面没有任何多余按钮，只留文字与专注思考。
