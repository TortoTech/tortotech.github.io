专注模式是一种逐段精读的阅读方式：正文切换为纵向滚动，当前段落自动居中并高亮，其余界面元素（侧边栏、AI 面板等）全部收起，让你一次只专注于一段内容。

## 开启与退出

- **阅读器菜单**：点击阅读器右上角的菜单按钮，选择「专注模式」；再次点击「经典模式」即可切回。
- **设置**：在 **设置 → 阅读 → 阅读模式** 中选择「专注」。阅读模式是全局设置，对所有书籍生效。

:::tip[PDF 书籍]
专注模式需要可重排的文本内容。扫描版 PDF 请先在阅读器中切换到 **OCR 版式**，再开启专注模式；从 OCR 版式切回原始 PDF 会自动退出专注模式。
:::

## 逐段导航

进入专注模式后，书籍按段落切分为一个个「焦点单元」（图片和表格各占一个单元），当前单元始终垂直居中，并以淡绿色底色标出：

| 操作 | 效果 |
| --- | --- |
| `↑` / `↓` | 上一段 / 下一段 |
| `←` / `→` | 上一章 / 下一章 |
| 鼠标滚轮 | 逐段滚动（一次一格） |
| 点击段落 | 直接将该段设为当前焦点 |
| 拖动滚动条 | 自动吸附到最近的段落 |

`Esc` 用于关闭浮层（操作栏、侧边栏、段落对话），不会退出专注模式；退出请使用菜单或设置中的模式开关。

## 段落级操作

对当前段落可以快速执行：

| 快捷键 | 操作 |
| --- | --- |
| `空格` | 打开段落旁的浮动操作栏 |
| `Tab` | 打开该段落的 AI 对话 |
| `1` | 高亮当前段落 |
| `2` | 为当前段落添加批注 |

- **段落对话**：每个段落拥有独立的 AI 聊天会话，打开时自动附上该段引用（显示为「段落 N · 章节标题」），围绕这一段追问、翻译、总结都不会串上下文。已有对话或批注的段落，右侧会显示小图标，点击即可回看。
- **搜索与目录**：`Ctrl+F` 全文搜索、目录跳转在专注模式下照常可用，跳转后焦点自动跟随到目标位置。
- 图片单元不支持高亮和批注；表格单元以边框标出。

## 为什么使用专注模式

- **减少干扰**：收起侧边栏与面板，只保留正文与当前段落。
- **掌控节奏**：逐段推进配合段落居中，视线不需要来回找位置，适合精读难懂或密度高的内容。
- **边读边想**：高亮、批注、AI 对话都挂在段落上，读到哪记到哪，想法不会脱离原文语境。
