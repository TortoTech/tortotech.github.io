Welcome to Torto — a focused, local-first native ebook reader for Windows and macOS.

## Setup Guides

- [OCR Providers](../guides/ocr-providers/): enable full-document OCR and reflow for scanned PDFs with PaddleOCR or MinerU.
- [Cloud Storage Providers](../guides/cloud-storage/): sync books, reading progress, highlights and notes across devices via WebDAV.

## Download

Get the latest Windows MSI or macOS DMG from the [download page](../download/), or head straight to [GitHub Releases](https://github.com/L-Chris/torto/releases).
