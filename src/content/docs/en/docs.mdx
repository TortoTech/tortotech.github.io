Welcome to Torto — a local-first native ebook reader built around Focus Mode for Windows, macOS and Android.

The Rust desktop app provides the complete Focus Mode, AI, translation and PDF OCR experience. The Android companion uses an independent Dart reading pipeline for multi-format reading, unified typography and WebDAV sync compatible with desktop Torto.

## Setup Guides

- [OCR Providers](../guides/ocr-providers/): enable full-document OCR and reflow for scanned PDFs with PaddleOCR or MinerU.
- [Cloud Storage Providers](../guides/cloud-storage/): sync books, reading progress, highlights and notes across devices via WebDAV.
- [Focus Mode](../guides/focus-mode/): paragraph-by-paragraph centered reading with per-paragraph AI chat and notes.

## Download

Get the latest Windows MSI, macOS DMG or Android APK from the [download page](../download/). Desktop installers are published in [Torto Releases](https://github.com/TortoTech/torto/releases), while Android APKs are in [Torto App Releases](https://github.com/TortoTech/torto-app/releases).
