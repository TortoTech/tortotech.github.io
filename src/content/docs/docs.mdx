欢迎使用 **Torto（小龟阅读）** —— 一款以专注模式为核心、本地优先的原生跨平台电子书阅读器，支持 Windows、macOS 与 Android。

Torto 致力于**重塑 PC 阅读体验**：一次只专注于一个有意义的阅读单元，继承 Typst 排版经验实现出版级中文版面，全键盘操作优先，带来纯净安宁的精读氛围。桌面端与 Android 端共享同一套与格式无关的阅读模型，并通过你自己的私有云盘直接同步。

---

## 核心能力一览

- **专注模式**：按内容语义逐单元阅读，视线稳定锚定，导航、高亮、批注、脚注与 AI 对话始终跟随当前内容。
- **原生渲染**：桌面端由 Rust 完成解析、排版、分页与渲染，不嵌入浏览器；Android 端由纯 Dart 阅读内核实现。
- **AI 辅助排版（可选）**：识别小节标题、有来源的引用与图表注释，折叠文内引用标记，并识别文字与图片公式（可复制 LaTeX）。
- **随段 AI 伴读（可选）**：对话绑定当前阅读单元，输入 `/` 唤起阅读技能、`@` 添加引用，回答附带原文出处。
- **阅读统计**：自动记录阅读时长、历史与读完状态，支持多设备云同步。
- **多格式与扫描 PDF**：EPUB、MOBI、AZW/AZW3、FB2/FBZ、CBZ、CHM 与 PDF；扫描版 PDF 可 OCR 转为可重排文字。

## 配置指南

- [专注模式精读指南](../guides/focus-mode/)：逐段自然推进、居中视线锚定、智能按句拆读（`3`）、随段折叠脚注（左 `Alt`）与无光标沉浸精读。
- [OCR 服务商配置指南](../guides/ocr-providers/)：为扫描版 PDF 开启智能文字识别与排版重排，支持 PaddleOCR 与 MinerU。
- [云盘服务商配置指南](../guides/cloud-storage/)：通过私有 WebDAV 协议在电脑与手机间直接双向同步书籍、进度、高亮、笔记与阅读统计（内置坚果云、InfiniCLOUD 等预设）。
