欢迎使用 Torto（小龟阅读）——一款以专注模式为核心、本地优先的原生电子书阅读器，支持 Windows、macOS 与 Android。

桌面端以 Rust 构建完整的专注阅读、AI、翻译与 PDF OCR 体验；Android 端使用独立的 Dart 阅读管线，提供多格式阅读、统一版式和与桌面端兼容的 WebDAV 同步。

## 配置指南

- [OCR 服务商配置](../guides/ocr-providers/)：为扫描版 PDF 开通全文 OCR 与重排，支持 PaddleOCR 与 MinerU。
- [云盘服务商配置](../guides/cloud-storage/)：通过 WebDAV 在多设备间同步书籍、阅读进度、划线与笔记。
- [专注模式](../guides/focus-mode/)：逐段居中高亮的精读模式，支持段落级 AI 对话与批注。

## 下载安装

前往[下载页](../download/)获取最新的 Windows MSI、macOS DMG 或 Android APK。桌面端安装包发布在 [Torto Releases](https://github.com/TortoTech/torto/releases)，Android 安装包发布在 [Torto App Releases](https://github.com/TortoTech/torto-app/releases)。
