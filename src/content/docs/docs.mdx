欢迎使用 Torto（小龟阅读）——一款专注、本地优先的原生电子书阅读器，支持 Windows 与 macOS。

## 配置指南

- [OCR 服务商配置](../guides/ocr-providers/)：为扫描版 PDF 开通全文 OCR 与重排，支持 PaddleOCR 与 MinerU。
- [云盘服务商配置](../guides/cloud-storage/)：通过 WebDAV 在多设备间同步书籍、阅读进度、划线与笔记。
- [专注模式](../guides/focus-mode/)：逐段居中高亮的精读模式，支持段落级 AI 对话与批注。

## 下载安装

前往[下载页](../download/)获取最新的 Windows MSI 或 macOS DMG 安装包，也可以直接访问 [GitHub Releases](https://github.com/TortoTech/torto/releases)。

## 遇到问题？

请到 [GitHub Issues](https://github.com/TortoTech/torto/issues) 提交反馈。
